# Noola Global — Static Website Starter

A five-page responsive static site using HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in Chrome, or use VS Code Live Server. No installation/build step required.

## Deploy with GitHub Pages
1. Create a **public** GitHub repository named `noola-global`.
2. Upload all files and folders **inside** this project folder to the repository root.
3. Commit the files.
4. Open **Settings → Pages → Build and deployment**.
5. Select **Deploy from a branch**, branch **main**, folder **/(root)**, and Save.
6. Your site will appear at `https://YOUR-USERNAME.github.io/noola-global/` after deployment.

## Before publishing
- Replace all sample text with approved company information.
- Replace `YOUR_EMAIL@example.com` in `contact.html`, `js/main.js`, and the footer (generated in all HTML pages).
- The contact form uses `mailto:` and **does not** send messages to a server.
- Add real articles, logos, policies, and business contact details.
- This project does not include a backend or HRM application.

## Custom domain
For `www.noolaglobal.com`, configure the custom domain in GitHub Pages and add a DNS `CNAME` record for `www` pointing to `YOUR-USERNAME.github.io`. Follow GitHub's current domain verification and apex redirect guidance. You must control the domain's DNS. DNS/domain registration is not included in free hosting. Do not modify existing DNS without checking current services.
